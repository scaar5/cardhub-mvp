2020-21 Topps Chrome UEFA Champions League provides soccer collectors with even more options in the revamped product.
While the format and output remain the same at one Chrome autograph per Hobby box, fans will definitely notice the expanded Refractor rainbow. Retail Blaster boxes also appear for the first time.
The online-exclusive 2020-21 Topps Chrome Sapphire Edition UEFA Champions League officially arrived in July.
For Chrome fans, that's not all as the '20-21 season is also treated to 2020-21 Topps Stadium Club Chrome UEFA Champions League and 2020-21 Topps Merlin Collection Chrome UEFA.
Even Match Attax has a chromium side via 2020-21 Topps Chrome Match Attax UEFA.
See also: 2019-20 Topps Chrome UEFA Champions League Cards
## 2020-21 Topps Chrome UEFA Champions League Soccer Base / Refractors
Likely to be a popular addition, the 100-card base set now includes RC logos for those young players who made UEFA debuts.
On top of that, the Chrome Refractor parallel lineup sees a large increase compared to last season, including several "Mini-Diamond" versions.

## 2020-21 Topps Chrome UEFA Champions League Soccer Inserts
Rolling in a few more changes, 2020-21 Topps Chrome UEFA Champions League offers new insert choices. Joga Bonito ("The Beautiful Game") highlights the biggest names with vivid colors and designs. These average 1:18 packs, so one per Hobby box.
Golazo (1:12 packs) is another debuting entry and it focuses on the top goal scorers.
Collectors can find the returning Future Stars (1:6 packs) line, as well.
As far as the Refractor parallels for the inserts, there's Aqua (#/199), which is new, plus Gold (#/50), Orange (#/25), Red (#/10), and SuperFractor (1/1) editions.
## 2020-21 Topps Chrome UEFA Champions League Autographs
Closing out the release, 2020-21 Topps Chrome UEFA Champions League features multiple players in the Chrome Autograph set.
Of course, there are multiple parallels to chase.
Look for limited insert signatures via numbered Future Stars Autographs (#/50), Golazo Autographs and Joga Bonito Autographs cards. These add Hobby-exclusive SuperFractors (1/1).
Release Date: June 11, 2021
Product Configuration: 4 cards per pack, 18 packs per box, 12 boxes per case
