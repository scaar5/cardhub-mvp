2020-21 Topps Chrome Sapphire Edition UEFA Champions League marks the second year of the online-exclusive product.
As usual, 2021 Topps 582 Montgomery Club members are treated to a pre-sale. The full public release came on July 21.
Oddly enough, it seems that cards (and boxes) appeared months ahead of the official release date. No official explanation was ever offered by Topps.
While the box price was $80 for the exact same format last year, 2020-21 Topps Chrome Sapphire UEFA sees a big increase to $250 per box.
See also: 2019-20 Topps Chrome Sapphire UEFA Champions League
## 2020-21 Topps Chrome Sapphire Edition UEFA Champions League Set Details
An exclusive blue version of the main 2020-21 Topps Chrome UEFA Champions League set, 2020-21 Topps Chrome Sapphire Edition UEFA Champions League offers a similar assortment of base cards, parallels and a few image variations.
Like last year, autographs are not part of the release.
Each 32-card 2020-21 Topps Chrome Sapphire Edition UEFA Champions League box contains two limited parallels.
